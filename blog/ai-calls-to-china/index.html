My AI Calls Restaurants in China

Twilio cannot call mainland China, full stop. So I built a second lane: a Mandarin-speaking AI agent, a SIP trunk, and a Telnyx number. Here is the whole pipeline, the code that places a call, and two real conversations with a Shanghai restaurant, transcribed in Chinese and English.

A build log with real call transcripts. The guest name, phone number, and restaurant name are redacted. Everything else is exactly what happened.

The short version

  • Twilio is my US voice provider, but it does not support outbound voice calls to mainland China. So it stays the US/Canada lane: domestic voice, SMS, one-time codes, alerts.
  • The China lane: ElevenLabs Conversational AI (a Mandarin voice agent) → a SIP trunk ("ElevenLabs AI Voice": sip.rtc.elevenlabs.io:5060, TCP) → Telnyx → the phone network → the restaurant.
  • Telnyx needed an ID verification (KYC) to unlock China (+86). Setup cost: $5 of account credit plus a US number (+1 213 727 0940, $1 upfront + $1/month) that shows up as the caller ID.
  • Two real calls, both transcribed below: a booking (7:30 and 8:00 were full, took 9:30 PM for 4, ¥500 per person minimum spend) and a confirmation (booking on file, name and number verified, no deposit needed).
  • A two minute call burns roughly 700 to 850 ElevenLabs credits. If the restaurant's line is busy (the network answers SIP 486), the system retries automatically, 20 minutes apart.

01The problem

Twilio is my US voice provider. Calls, texts, one-time codes, build alerts. Rock solid. One problem: it does not do outbound voice calls to mainland China. Not "it's expensive." Not "it's in beta." It just doesn't.

I needed to phone restaurants in Shanghai and Beijing to book dinner tables, in Mandarin, while I sat in California. The restaurant industry there still runs on phone calls. No online booking, no email, just a landline and a person who answers it.

So I built a second lane, China-only, with an AI doing the talking. Here is exactly how a call travels.

03Two lanes

Twilio didn't get fired. It just doesn't go to China. So now there are two lanes, each doing what it's good at:

Twilio

The home lane · US + Canada
  • Domestic voice calls
  • SMS and one-time codes
  • Build and alert notifications
  • Cannot call mainland China, at any price

Telnyx

The China lane · +86 unlocked
  • Outbound voice to mainland China
  • SIP trunk friendly, plays nice with ElevenLabs
  • Needed ID verification (KYC) to unlock the +86 country
  • $5 credit to start, $1 number ($1/month)

04Placing a call

One API call starts everything. You hand ElevenLabs three things: which agent talks, which phone identity it calls from (the SIP trunk), and the destination number. ElevenLabs opens the trunk to Telnyx, Telnyx dials out, and the agent starts talking when a human picks up.

const res = await fetch(
  "https://api.elevenlabs.io/v1/convai/sip-trunk/outbound-call",
  {
    method: "POST",
    headers: {
      // placeholder: use a real key from your ElevenLabs dashboard
      "xi-api-key": "ELEVENLABS_API_KEY",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      agent_id: "agent_xxxx",              // the Mandarin booking agent
      agent_phone_number_id: "phnum_xxxx", // the SIP trunk identity
      to_number: "+8621xxxxxxxx"           // the restaurant, E.164 format
    })
  }
);
const call = await res.json();
// poll GET /v1/convai/conversations/{conversation_id}
// until the call completes, then read the transcript

If the line is busy, the network answers with SIP 486 and the API reports a failure. The fix is boring and effective: schedule retries 20 minutes apart and try again. One Beijing restaurant's line came back busy twice in a row, so the retry job just waits and redials.

05The prompt is the product

The voice is ElevenLabs. The manners are a prompt. The agent opens with one neutral line: “您好，请问是…餐厅吗？我想订个位子。” (Hello, is this … restaurant? I'd like to book a table.) That's the whole introduction. It never claims to be the guest. It never says the word AI. If the restaurant asks who is calling, it says it's the guest's assistant, and only then. It gives the guest's name only when asked for the booking name.

Honest footnote: the first version of the prompt had the agent introduce itself as "an AI assistant." You can hear it in the first transcript below, because that is what actually happened. It was rewritten to the neutral version right after that call. The lesson stuck: the prompt is the product. Nobody on the other end of a restaurant line needs a vocabulary lesson about artificial intelligence. They need a table for four.

07What it costs

The full bill for a China-capable calling lane:

Per call

ElevenLabs
  • Roughly 700 to 850 credits for a two minute call
  • That covers the voice, the language model, and the phone time

One time setup

Telnyx
  • $5 of account credit to fund the account
  • $1 for the US number, then $1/month
  • ID verification (KYC): free, just paperwork

The alternative was me calling in my beginner Mandarin, which would have cost nothing and accomplished less. For about seven dollars plus AI credits, I now have a Mandarin-speaking assistant that books tables across the Pacific while I sleep. That is a trade I will make every time.
