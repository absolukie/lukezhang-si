1. What OpenAI dropped

The repo is openai/math, Apache licensed. 722 manuscripts in 372 families, produced by an internal frontier model at roughly three hours of heavy thinking compute per result, drawn from about 4,000 posed problems. Some results already come with Lean 4 formalizations, which is the part that caught my eye: a machine-checked proof is either right or it does not compile. There is no partial credit and no hand-waving.

The headline families include the irrationality exponent of π, the Mahler conjectures, Kaplansky's direct-finiteness conjecture in characteristic two, the Hodge conjecture for CM abelian varieties, and a zero-free region for the Riemann zeta function. Heavyweight stuff. The π one is my favorite: it asks how well π can be approximated by fractions, which is a precise way of measuring how irrational a number is.

2. The gap I actually wanted to fill

Here is the thing about a Lean proof of the irrationality exponent of π: you cannot practice on it. It is the top of a mountain with no trail. I wanted the trail. So I built the smallest possible practice set that points at the same mountain: start with baby steps in Lean's tactic language, then prove √2 is irrational from scratch, with every step explained.

If the π result measures how irrational a number is, the √2 proof is where that road starts: the 2,500-year-old argument that some numbers simply are not fractions, now in a form a computer can check.

4. What learning Lean feels like

Lean is a programming language where the program is a proof and the compiler is the referee. You write what you believe, and it tells you exactly which step does not hold up. There is something addictive about it: every error message is a precise pointer at the gap in your reasoning. Mathematicians have always had referees. Now the referee runs in milliseconds and never gets tired.

The honest part: the first hour is humbling. Things you "know" turn out to have twelve hidden steps. n + 0 = n is free, but 0 + n = n needs induction, because addition is defined by recursion on the right. You learn how much of your own math runs on vibes.

Then it clicks, and you start seeing proofs as programs. The √2 proof in the repo is 40 lines with comments. The computer checked every one of them. Euclid never got that.

5. Try it yourself

The repo has three parts: Basics.lean (tactics from zero, all compiling), Irrational.lean (the full √2 proof, heavily commented), and exercises with the answers removed: √3, then √p for any prime p. Install Lean with elan, clone, run lake build. If it compiles, you are right. That is the whole grading system.

Somewhere in the openai/math repo, a machine proved something about π that no human had managed. My contribution is smaller: one ancient theorem, checked by a laptop, and a trailhead for anyone who wants to start climbing. Take notes, OpenAI.
