Shipped spec

Everything currently live on the refine page, as of 2026-10-05.

  • Notch handle — a 6×24px white tick on a 2px full-height divider. No circle, no chevrons; grows 1.35× while dragging.
  • Grab-anytime — touch-action:none + pointer capture: the slider answers mid-scroll, not just when the page is still.
  • 12px direction lock — mostly-horizontal drives the divider 1:1; mostly-vertical scrolls the page itself 1:1 with momentum on release.
  • Tap-to-glide — a tap (<6px, <300ms) glides the divider to the tap point, ~380ms ease-out; grabbing mid-glide cancels it.
  • Clamped 2–98% — the divider never parks fully off either edge; divider and top layer move in rAF.
  • Keyboard — ←/→ nudge 4%, Home/End jump; role="slider" with live aria-valuenow.
  • Corner labels — Unedited/Edited chips, non-interactive, pointer-events none.
  • Container never changes size — fixed 16:10 box, so dragging can't shift the page; no double-tap zoom anywhere.
  • Embed snippet — copies a self-contained HTML/CSS/JS block for design docs and blog posts.
