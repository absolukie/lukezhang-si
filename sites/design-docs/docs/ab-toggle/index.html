Shipped spec

Everything currently live in the lab, as of 2026-10-05.

  • One button, not two pills — the entire switch is a single role="switch" button. Tapping anywhere on it flips; there is no way to "pick a side."
  • Every tap flips — no dead taps: hitting the active side flips too, so spamming alternates A/B/A/B.
  • Sliding thumb — a dark thumb glides (~280ms, slight overshoot) to cover the active side's label; the thumb always shows what's currently displayed.
  • Stage crossfade — the two versions dissolve over ~450ms; reduced-motion disables it.
  • Keyboard + screen reader — native button, so Space/Enter flip; aria-checked mirrors state, label names both sides.
  • Generous tap target — full-width up to 420px, 16px labels, touch-action:manipulation: rapid taps never zoom.
  • Embed snippet — copies a self-contained HTML/CSS/JS block; the wiring function is dependency-free so it stringifies cleanly.
