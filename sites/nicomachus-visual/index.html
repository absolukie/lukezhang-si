Nicomachus's Theorem — a visual proof

01 / 05 · Assemble
A visual proof: each cube k³ forms the border between squares of side Tₖ₋₁ and Tₖ, where Tₖ = k(k+1)/2.

1³ + 2³ + 3³ + 4³ = (1 + 2 + 3 + 4)²

1 + 8 + 27 + 64 = 100 = 10²

1³ + 2³ + ⋯ + n³ = (1 + 2 + ⋯ + n)²

Four cubes: 1³, 2³, 3³, 4³ — that's 1 + 8 + 27 + 64 tiny unit cubes.
