# Replay
**Concept:** Repro Lab · **Category:** AI Agents / Infrastructure

**One-liner:** Deterministically reproduce problematic agent runs with pinned seeds.

## Startup thesis
Flaky agent runs are the #1 tax on agent teams: a failure you cannot reproduce is a failure you cannot fix. Repro Lab makes every run bit-for-bit replayable by pinning seeds, fixtures, tool mocks, and the virtual clock — turning "works on my machine" into a hash you can compare.

## Architecture
Single-file client app. Runs are generated by a seeded RNG (Kit.rng) over a fixed step list; the failure site is a deterministic function of the seed. Replay animates the step timeline, then compares FNV hashes across replays. Same seed → identical steps, identical failure, identical hash — real determinism, verified in the UI.

## Magic moment
The app auto-replays seed 4821 on load and fails at the exact same step; hit "Replay again" and the two hashes match — determinism, proven, not promised.

## Monetization
Team SaaS ($39/seat/mo) with run-history retention; enterprise tier adds cassette storage for network replay and CI integration that auto-reproduces flaky eval failures.

## Known limitations
Simulated tool steps, not real browser/tool execution; FNV hash is a demo-grade checksum; no export to real CI yet.

## Next 3 features
1) Record/replay proxy for real HTTP tool calls. 2) One-click "bisect the seed space" to find minimal failing seeds. 3) CI bot that comments the repro hash on flaky eval failures.
